## 📖 About This Repository

**Jabri Lab** is the experimental playground where new algorithms, theories, and code are tested before being rolled out to the main repositories. It contains **9 submodules (Jabri-5, Jabri-28, Jabri-Gravity, Jabri-Spacetime, Jabri-Darkenergy, Jabri-Planck, Jabri-Hubble, Jabri-Periodic, Jabri-all)** for various specialized experiments in physics and mathematics.

**Key Features:**
- 🧪 **9 Experimental Projects** – Each project explores a different aspect of the Zx function and physics expansions.
- 📄 **Full Documentation** – Each project includes: Data, Image, Paper (PDF), Notebook (Jupyter), and LaTeX source.
- 🔬 **Reproducible Research** – All notebooks are versioned and ready to run.
- 🌐 **Unified Framework** – All projects are built on the Zx function and Al-Jabri Identity (`Z + C + A = 1`).
